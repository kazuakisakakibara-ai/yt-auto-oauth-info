Privacy Policy

Last updated: September 12, 2026

Scope

YT Auto Playlist Sync is a personal-use Windows application. It synchronizes YouTube videos into playlists selected and controlled by its user.

Google and YouTube data accessed

After the user grants Google OAuth authorization, the application accesses only the YouTube data needed to perform the configured synchronization: playlist contents, channel identifiers, and video metadata. It adds and removes playlist items only in playlists configured by the user.

Storage and sharing

The application runs locally on the user's Windows computer. OAuth tokens and application configuration are stored locally by the application. The application does not operate a remote server and does not sell, rent, share, or transfer Google or YouTube user data to third parties.

Retention and revocation

The user may revoke the application's Google access at any time through their Google Account security settings. The user may also remove the locally stored OAuth token from the application folder. Removing the token requires authorization again before the application can access YouTube on that computer.

Changes

This policy may be updated if the application's data handling changes. The current version is published on this page.
