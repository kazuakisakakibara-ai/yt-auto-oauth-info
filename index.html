YT Auto Playlist Sync

YT Auto Playlist Sync is a personal-use Windows application that keeps designated YouTube playlists synchronized with recent uploads from channels selected by its user.

What the application does

  • Reads the current contents of playlists configured by the user.
  • Reads recent public uploads from channels configured by the user.
  • Adds missing matching videos to the configured playlists and removes playlist items that no longer match the user's configured rules.

Data handling

The application runs locally on the user's Windows computer. Google OAuth authorization is used only to access and manage the user's configured YouTube playlists. OAuth tokens are stored locally on that computer. The application does not sell, share, or transmit YouTube data to third-party services.
